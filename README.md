# Vértice

Plataforma de Inteligência Territorial baseada em Evidências.

Material de apoio ao simpósio, reunindo os links das aplicações apresentadas. Escaneie o QR Code do slide final, escolha uma aplicação e acesse o painel.

## Aplicações apresentadas

- Vértice — acesso principal.
- Painel Pró-Gestão Saúde.
- Monitoramento de Queimadas.
- Sub-bacia Hidrográfica do Rio Palmeira.
- Planejamento da Expansão de Creches.
- Unidades de Conservação Estaduais.

Saúde e sub-bacia incluem acessos a diferentes visualizações utilizadas na apresentação.

As aplicações são hospedadas pelo TCE-RO.
